# AudioCaps splits used by the RECAP paper

Generated by `scripts/make_paper_split.py` from the reference code's
`data/{train,dev,test}_audiocaps.csv` (github.com/Sreyan88/RECAP, commit
832ad8a), mapped onto this repo's `youtube_id`/`start_time` keys.

| split | clips | captions |
|---|---|---|
| train | 42,797 | 42,797 |
| val | 345 | 1,725 |
| test | 748 | 3,740 |

Every clip is also in `data/{train,val,test}.csv`, so the encoder features,
audio embeddings and retrieval caches built for the full splits cover these
subsets. Caption text comes from the reference CSVs, which fix typos and
spacing in some AudioCaps captions.

Use `train.csv` here (as training data and as the retrieval datastore) and
`test.csv` here (for evaluation) to compare with the numbers in the paper.
Placeholder captions in `train.csv` (8 rows) are dropped automatically by
`data/caption_filter.py`.
